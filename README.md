# Say What Actually Broke

One line of software error copy, at most 200 characters, that tells the user
the brutal truth about what went wrong — and makes them laugh on the way.

## The line

> Your file didn't save — the disk is full, the backup failed first, and autosave was on its lunch break. Delete something, then try again.

## Why this failure

A failed save is the most dreaded error in software, and the usual copy hides
behind "Something went wrong". This line names the real failure instead: the
disk is full. It then tells the rest of the ugly truth — the backup failed
first, and autosave, the feature users trust to rescue them, was doing
nothing. The joke lands in the same breath as the diagnosis, and the line
still ends with the one thing the user can actually do about it: free up
space and try again.

That is copy a real team could ship in a dialog: specific, honest, funny,
and useful.

## Entry

- `main.py` — prints the error line exactly once, with no extra output.
- `entry.txt` — the exact same line, byte-for-byte.
